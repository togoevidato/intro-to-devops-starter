# intro-to-devops-app

Starter repository for the Intro to DevOps course homework. You will extend this app across the modules (endpoints, database, CI/CD, deployment, security).

**Start here:** [PROJECT-REQUIREMENTS.md](./PROJECT-REQUIREMENTS.md) — what the application must do and how it maps to the course.
## Branching strategy

This project uses GitHub Flow.

- `main` is the stable branch.
- All changes are developed in feature branches.
- Feature branches are merged into `main` through Pull Requests.
- After a Pull Request is merged, the feature branch is deleted.
- Before starting new work, local `main` is updated with `git pull origin main`.
